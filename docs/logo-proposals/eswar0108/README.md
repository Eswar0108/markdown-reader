# Logo proposals — issue #330

Original submissions for **[#330 — Redesign the App Logo](https://github.com/petertzy/markdown-reader/issues/330)**
by [@Eswar0108](https://github.com/Eswar0108). All three are hand-authored,
font-free SVGs (pure paths) — free to use, distribute, and adapt under the
project's license.

| # | File | Concept |
|---|------|---------|
| A | `a-split-page.svg` / `a-*.png` | **Split Page** — one document split into markdown source (navy) and rendered preview (green): the app's split view in a single glyph. Boldest silhouette at 32 px. |
| B | `b-mdown-mark.svg` / `b-*.png` | **M↓ Mark** — a bold M with the Markdown down-arrow, stacked and centered: the universal Markdown symbol as a project identity. |
| C | `c-open-reader.svg` / `c-*.png` | **Open Reader** — two leaning pages forming an open book / two panes: the "Reader" in Markdown Reader. |

Shared palette: navy gradient tile `#16375A → #0B1E33`, markdown green
`#2DA56A`, white marks. Every design ships at 512/128/32 px; `contact-sheet.png`
shows all three on light and dark backgrounds with a 4× zoom of the 32 px
render.
